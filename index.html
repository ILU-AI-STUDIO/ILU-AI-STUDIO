Whole-photo AI super-resolution. The model downloads online; enhancement runs in your browser. Free, no API key.

Real AI model: ESRGAN-Slim 2× super-resolution improves the whole image (not just the face). First run downloads TensorFlow.js and model files and may take several minutes. Photo processing stays on this device. This is not Remini's proprietary face-restoration model, so results vary and missing facial details may not be perfectly recovered. About ILU AI STUDIO

A free-first personal photo workspace.

This version includes local photo adjustments, ESRGAN 2× AI super-resolution, conventional 2×/4× resizing, and a beta AI background remover using the open-source @imgly/background-removal browser library. It does not include generative AI enhancement, AI super-resolution, face restoration, object removal, login or cloud sync.

No paid API or billing is used by the included editor. Hosting a public HTTPS version is a separate deployment step and depends on the hosting provider's free-tier terms.
